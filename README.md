# Badzlina Razi — Voice Talent Portfolio

Live site: **https://badzlinavoicesite.netlify.app/**

Bilingual (English / Bahasa Malaysia) voice-over portfolio for
**Nur Badzlina Razi** — voice talent, voice actor, and voice-over artist
based in Malaysia, available worldwide.

## What's inside

| File | Purpose |
|------|---------|
| `index.html` | The website |
| `style.css` | Design & responsive layout |
| `main.js` | Interactivity: language toggle, genre tabs, audio players, booking form |
| `cinematic.js` | Scroll animations (GSAP ScrollTrigger + Splitting.js) + hero voice canvas |
| `profile.jpg` | Profile photo |
| `audio/` | Demo reel + genre voice samples |

## Features

- 🎙️ Full demo reel + 21 voice samples across 10 genres (EN & BM)
- 🎬 Cinematic scroll experience — fluid chapter colours, letter-by-letter titles, living voice canvas
- 🌐 Bilingual English / Bahasa Malaysia toggle
- 📋 Booking form — emails bookings via Formspree, plus one-tap WhatsApp send
- 💬 Floating WhatsApp chat button
- 💱 Payment in MYR, USD & GBP with deposit selection

## Hosting

Static site — hosted free on **Netlify**. No server required
(bookings are handled by [Formspree](https://formspree.io)).
